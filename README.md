# 巡演舞台调度与走位编排工作台

面向剧院巡演团队的舞台执行工作台，覆盖演员与道具调度、舞台走位、执行提示、留言协同、版本回退、基线锁定和演出文档打印。

## 技术栈

Vue 3 + Element Plus + Pinia + Vue Router + TanStack Query + Axios + MSW + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62044`。

## 核心工作流

- 在舞台平面图中选择走位，编辑入场点、退场点、路线节点和触发时机。
- 在同一脚本时间线中维护灯光、音响、道具与执行提示。
- 添加部门留言、标记问题并生成修改版本；撤销、重做和离线草稿会自动保存。
- 锁定演出基线，并从打印中心输出走位表和执行清单。

## 离线协同与合并

- **离线批次**：断网期间的修改进入本地批次（localStorage 持久化），回网后自动同步；同步失败时批次保留在本地，可一键重试。
- **三方合并**：回网后不再整份覆盖。服务器以批次基线版本为参照做字段级三方合并，没撞车的字段直接并入。
- **冲突裁决**：同一走位或留言两边都改过时，两版都保留在裁决队列中逐条裁定；未裁完不能锁定演出基线。
- **幂等重传**：每个批次有唯一批次号，同号重传服务器直接返回上次结果，不会生成重复版本（侧边栏"故障演练"可模拟两类同步故障）。
- **失效联动**：演出基线、确认状态或时间码一变，受影响的打印清单立即标记"已失效"需重新核对，相关已解决留言待办自动重开等待复核。
